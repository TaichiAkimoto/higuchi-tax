プライバシーポリシー

最終更新日: 2026年1月31日

めんどい（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、個人情報の保護に最大限の注意を払います。 本プライバシーポリシーは、本アプリがどのような情報を収集し、どのように使用するかを説明します。

1. 収集する情報

本アプリは以下の情報を収集します：

  • 匿名ユーザー識別子: Firebase匿名認証により自動生成される一意のユーザーID（UID）
  • 入力されたタスク内容: ユーザーが入力した「やりたくないこと」のテキスト
  • 音声データ（音声入力使用時のみ）: デバイス上でのみ処理され、サーバーには送信されません

2. 個人を特定できる情報の非収集

本アプリは以下の情報を一切収集しません：

  • 氏名、メールアドレス、電話番号などの個人情報
  • 位置情報
  • デバイスの連絡先やカレンダー
  • 写真やカメラへのアクセス

3. 情報の使用目的

収集した情報は以下の目的でのみ使用されます：

  • タスク分解サービスの提供: 入力されたタスクをAIでマイクロステップに分解
  • ユーザー認証: Firebase匿名認証による安全なAPI通信
  • 利用制限の実施: 不正利用防止のためのレート制限（10リクエスト/分）

4. 情報の保存と管理

  • 一時的な保存: 入力されたタスクとAI生成結果はデバイス上のメモリにのみ保存され、アプリ終了時に削除されます
  • サーバーログ: APIリクエストのログは最大7日間保持され、その後自動削除されます
  • 永続的なデータベース保存なし: ユーザーのタスク内容や履歴を永続的に保存することはありません

5. 第三者サービスの使用

本アプリは以下の第三者サービスを使用します：

  • Firebase Authentication (Google): 匿名ユーザー認証
    Firebase プライバシーポリシー
  • Google Gemini API: タスク分解とAI励まし生成
    Google プライバシーポリシー
  • Google Cloud Run: バックエンドAPIホスティング
    Google Cloud プライバシー通知

6. 音声認識について

  • 音声入力機能はAppleの音声認識APIを使用します
  • 音声データはデバイス上でのみ処理され、外部サーバーには送信されません
  • 音声認識の使用には初回起動時に明示的な許可が必要です

7. データの共有と開示

本アプリは以下の場合を除き、ユーザーの情報を第三者と共有しません：

  • 法令に基づく開示要求がある場合
  • ユーザーの生命、身体、財産を保護するために必要な場合

8. 子どものプライバシー

本アプリは13歳未満の子どもから意図的に個人情報を収集しません。 保護者の方で、お子様が個人情報を提供したと思われる場合は、下記連絡先までご連絡ください。

9. セキュリティ

  • 全ての通信はHTTPS暗号化で保護されます
  • Firebase IDトークンによるAPI認証を実施
  • レート制限により不正利用を防止

10. プライバシーポリシーの変更

本プライバシーポリシーは、法令の変更やサービスの改善に伴い、予告なく変更される場合があります。 変更後のプライバシーポリシーは、本ページに掲載した時点で効力を生じます。

Privacy Policy

Last Updated: January 31, 2026

1. Information We Collect

  • Anonymous User Identifier: A unique user ID (UID) automatically generated by Firebase Anonymous Authentication
  • Task Input: Text describing tasks you want help with
  • Voice Data (when using voice input): Processed only on-device, never sent to servers

2. Information We Do NOT Collect

  • Personal information (name, email, phone number)
  • Location data
  • Contacts or calendar access
  • Photos or camera access

3. How We Use Information

  • Provide task decomposition service via AI
  • Authenticate users securely
  • Prevent abuse with rate limiting (10 requests/minute)

4. Data Storage

  • Task inputs are stored only in device memory and deleted when app closes
  • Server logs retained for maximum 7 days
  • No persistent database storage of user content

5. Third-Party Services

  • Firebase Authentication (Google) - Anonymous auth
  • Google Gemini API - AI task decomposition
  • Google Cloud Run - Backend hosting
